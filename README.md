# Kritarth & Palak — Royal Wedding Digital Invitation 👑✨

A royal, traditional, and mobile-optimized Indian wedding digital invitation website for **Kritarth & Palak**, built with Next.js (App Router), TypeScript, and Tailwind CSS.

## 🌸 Auspicious Dates & Location
- **Dates:** 18 November – 21 November 2026
- **Main Wedding Ceremony (Paanigrahan & Saptapadi):** 21 November 2026, 02:30 PM
- **Grand Feast (Madhurya Bhoj):** 21 November 2026 (Evening)
- **Venue:** Swagat Marriage Garden, Kurwai Road, Sironj, Dist. Vidisha (M.P.)
- **Family:** Soni Parivar, Sironj (M.P.)

---

## 🏛️ Features

1. **Cinematic Palace Door Opening:** Traditional royal Rajasthani palace double-door opening animation with Lord Ganesha motif and auspicious Sanskrit shlokas.
2. **Authentic Source of Truth:** Every ritual, timing, venue, deity invocation, and family name directly from the original invitation card.
3. **Updated Matrikul Details:** Accurately reflects **स्व. श्री गिरिराज जी** in `मातृकुल`.
4. **Interactive Timeline:** Date-filtered ceremonies (18 Nov, 20 Nov, 21 Nov) with direct **1-tap Google Calendar Reminders**.
5. **Live Muhurat Countdown:** Real-time countdown timer to the auspicious wedding day and hours.
6. **Venue & Navigation:** Integrated Google Maps navigation for Swagat Marriage Garden, Sironj.
7. **WhatsApp-First Experience:** Pre-composed WhatsApp invitations and interactive wish-book for sending congratulations directly to the Soni family.
8. **Royal Background Shehnai Player:** Ambient traditional Indian wedding instrumental music player with play/pause controls.
9. **100% Vercel & Mobile Ready:** Fast, static-first Next.js architecture with zero unnecessary backends or heavy runtime overhead.

## 🚀 Local Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Create optimized production build
npm run build

# Start production server
npm run start
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub.
2. Import the repository into your [Vercel Dashboard](https://vercel.com/new).
3. Vercel automatically detects Next.js; leave the build command as `next build`.
4. Click **Deploy**.
